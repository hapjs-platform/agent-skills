## 使用提示

1. 所有文档文件都是 Markdown 格式，直接 Read 即可
2. 组件文件通常包含：概述、属性、样式、事件、方法、示例代码
3. 接口文件通常包含：接口声明、导入方式、方法定义、参数说明、示例代码、权限要求
4. 教程文件更详细，包含原理讲解和完整的示例代码
5. 如果用户问的问题涉及多个方面（如"长列表"涉及组件 + 性能优化），需要同时读取多个相关文件
6. **最佳实践**、**常见问题**、**性能优化** 三个模块在独立目录中，回答时根据问题类型交叉引用：
   - 用户问"怎么做" → 读 `best-practices/`
   - 用户遇到异常/报错 → 读 `common-pitfalls/`
   - 用户关注速度/体积 → 读 `performance/`
