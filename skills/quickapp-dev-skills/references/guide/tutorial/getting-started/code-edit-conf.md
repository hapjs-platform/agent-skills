# 代码编辑配置

> 介绍一些常用的编辑器的配置，提高开发效率

通过本节，你将学会：

- 使用 Visual Studio Code 开发
- 使用 WebStorm 开发
- 使用 Sublime Text 开发

## 使用 Visual Studio Code 开发

#### 下载安装

点击跳转[下载 Visual Studio Code](https://code.visualstudio.com/Download)

#### 安装`Hap Extension`

启动 Visual Studio Code，打开项目，点击左上侧`扩展`，搜索`hap`，安装`Hap Extension`，如下图所示：

点击`重新加载`激活`Hap Extension`，激活后如下图所示：

#### 效果展示

想了解`Hap Extension`的支持的功能，详见[Hap Extension](https://marketplace.visualstudio.com/items?itemName=hap.Hap)

## 使用 WebStorm 开发

#### 下载安装

点击跳转[下载 Webstorm](https://www.jetbrains.com/webstorm/download/)

### 关联 HTML 配置

启动 WebStorm，打开项目，点击顶部菜单栏`File --> Settings`，打开 WebStorm 配置界面

在配置界面选择`Editor --> File Types`，找到`HTML`，增加通配符`*.ux`，如下图所示：
