# 性能面板工具 `1100+`

> 从`1100`版本开始，快应用引擎提供性能面板功能，帮助开发者更好地了解快应用性能，从而开发出更高质量的快应用程序。此外，性能面板也为开发者提供了一些实用便捷的小功能。

使用 `1100` 或更高版本的调试器，当目标引擎版本不低于 `1100` 时，将显示性能面板勾选框，勾选后即可开启性能面板。

## 性能面板指标说明

| 指标     | 说明                                           |
| -------- | ---------------------------------------------- |
| FPS      | 流畅度指标，越接近于设备屏幕刷新率，表示越流畅 |
| MEM      | 快应用进程的内存占用（Total Pss）              |
| API      | 接口调用频率                                   |
| CPU      | 快应用进程的 CPU 使用率                        |
| PageTime | 快应用页面创建的耗时                           |

## 功能介绍

### 告警提示

运行时检查组件和接口是否使用合理，给出一些性能优化方面的建议，包括：

- `<image>` 组件设置的图片源不宜过大，过大图片的定义：原始像素数 > 使用像素数 \* 2
- 启动阶段屏幕可见区域外渲染元素数量不宜过多，建议不超过总元素数量的一半
- 检查`<list>` 组件使用是否合理，不同 DOM 结构的 子组件`<list-item>` 不应该设置相同的 type 属性
- 页面创建阶段接口调用次数不宜过多，建议不超过 40 次
- 页面元素层级数不宜过大，DOM 层级数建议不大于 14，原生 view 层级数建议不大于 20
