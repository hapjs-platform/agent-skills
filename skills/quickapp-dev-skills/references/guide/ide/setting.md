# 设置主题颜色

> 通过本节你将学会设置 IDE 的主题颜色。

通过本节你将学会：

- [设置主题颜色](#设置主题颜色)
- [切换中英文](#切换中英文)
- [设置 toolkit 调试端口](#设置-toolkit-调试端口)

1. IDE 主题颜色

   通过「**首选项**」「**主题颜色**」菜单，打开 IDE 主题颜色选择面板。按上下箭头可以预览不同主题，点 `Enter` 键确定使用主题。

2. 模拟器 devtools 主题颜色

   通过「**首选项**」「**设置**」菜单，打开设置面板。

   搜索 `devtools theme`, 下拉选择 devtools 的主题颜色。选择后，模拟器和 devtools 均会刷新，使 devtools 的主题颜色生效。

## 切换中英文

- 打开「**首选项**」「**选择语言**」菜单，选择「**中文**」或「**英文**」，进行语言切换。

- 配置后，需要重新加载窗口才会生效。操作如下：通过快捷键 `Ctrl + Shift + P` (Mac：`Cmd + Shift + P`) 调起「**命令面板**」，输入 `开发人员: 重新加载窗口`。

## 设置 toolkit 调试端口

- 通过「**首选项**」「**设置**」菜单，打开设置面板。

* 搜索 `toolkit port`, 修改端口号。

* 配置后，需要重新加载窗口才会生效。操作如下：通过快捷键 `Ctrl + Shift + P` (Mac：`Cmd + Shift + P`) 调起「**命令面板**」，输入 `开发人员: 重新加载窗口`。
