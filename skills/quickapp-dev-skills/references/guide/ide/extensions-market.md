# 插件市场

> 在开发工具的插件市场中，用户可以根据自己的需求下载和使用插件。

## 如何使用插件市场

1. 进入插件市场

   - 点击左边栏的「**插件市场**」图标，进入插件市场。
   - 插件市场会为用户提供常用的插件，包括快应用所需要的引擎包、模版包。

2. 搜索插件

   - 在搜索栏输入插件名称，可以搜索插件，支持模糊匹配。比如输入 `hap`，展示插件名包含 `hap` 的插件：

   - 插件市场还支持条件搜索，输入 `@xxxx`，搜索满足对应条件的插件：

     - @builtin：内置的插件
     - @disabled：禁用的插件
     - @enabled：启用的插件
     - @installed：安装的插件
     - @outdated：过期的插件
     - @recommend：开发工具推荐的插件
     - @id：根据插件 id 查询。插件 id 的格式为 `插件发布者.插件名`，比如快应用模版插件的 id 为 `HapTeam.hap-projects`。
     - @ext：一般用于搜索指定文件类型的语法插件。比如，输入 `@ext:qxml`，搜索 `qxml` 文件的语法插件。
     - @tag：一般用于搜索有指定关键字的插件。关键字，是指插件的 `package.json` 中的 `keywords` 字段。例如，搜索 `快应用`，返回带`快应用`关键字的插件。
     - @sort：根据条件进行排序。比如 `@sort:installs`， 是根据安装量排序。
     - @category：查询对应类型的插件。比如 `@category:"themes"`，返回主题插件。

3) 安装插件

   - 点击「**安装**」按键，可安装插件。

   - 安装成功后，如果插件未生效，则需要重新加载窗口。重新加载窗口的操作如下：通过快捷键 `Ctrl + Shift + P` (Mac：`Cmd + Shift + P`) 调起「**命令面板**」，输入 `开发人员: 重新加载窗口`。

4) 卸载插件

   - 点击「**卸载**」按键，可卸载插件。

   - 再点击「**需要重新加载**」按键，重新加载窗口，使卸载生效。

5) 禁用、启用插件

   - 禁用、启用插件的操作，和安装、卸载插件类似。点击插件的设置图标，弹出下拉菜单，选择 `禁用` 或 `启用`，即可完成操作。

6) 更多功能

   - 点击插件市场的「**...**」按键，可以使用插件市场的更多功能。具体如下：

     - 视图：查看不同类型的插件。
     - 检查扩展更新：检查是否有需要更新的插件。
     - 禁用自动更新扩展：插件安装后，默认会自动更新，使用该功能后，就不会再自动更新。
     - 启用所有扩展/禁用所有已安装扩展：如字面意思，启用和禁用所有插件。
     - 从 VSIX 安装...：从本地安装安装插件。点击后，选取要安装的插件（vsix 文件），即可安装。
