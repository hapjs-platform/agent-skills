# 工具栏界面

> 了解快应用开发工具（简称 IDE）工具栏界面上各个模块的功能。

## 工具栏界面

### 简介

在快应用开发工具（简称 IDE）的工具栏界面，包含 IDE 中最常用的主要功能。

- [关联快应用](./associate-quickapp.md)，能够关联官网开发者中心的快应用
- [编译模式](./compile.md#编译模式)，能够配置启动页和启动参数
- 点击编辑器、调试器、模拟器，可以分别显示与隐藏这三个区域
- [骨架屏](./skeleton.md)，能够帮助生成骨架屏
- [清缓存](./clear-cache.md)，能够清楚 ide 的相关缓存
- [远程预览](./remote-preview.md)，没有局域网和调试器扫码的限制下远程扫码预览
- [USB 调试](./machine-debug.md)，能够快速调试快应用
- [打包](./package.md)，能够生成正式 RPK 包，打包之后可上传包至包管理平台
- [上传](./upload-quickapp.md)，能够上传至快应用官方网站后台
- [分享](./share.md)，方便分享代码给他人，他人通过链接可直接打开
- [资源帮助](./resources.md)，提供快应用开发相关资源入口
- 登录，可登录快应用官网，提供包管理平台及官网开发者中心的链接跳转
