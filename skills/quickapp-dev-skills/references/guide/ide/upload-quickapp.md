# 上传

> 帮助用户快捷打包上传至官网开发者中心。

通过本节你将学会：

- [上传至官网开发者中心](#上传至官网开发者中心)
- [上传至包管理平台](#上传至包管理平台)

## 上传至官网开发者中心

1. 可以通过点击顶部工具栏的「**上传**」按钮执行功能。

2. 检查证书

   检测在工程的 sign 目录中是否存在 certificate.pem 和 private.pem 文件。如不存在则提示用户去[生成证书](./certification.html)。

3. 上传 rpk 包

   - 上传 rpk 包，需要预先登录快应用官网帐号。

   - 登录成功，再次点击顶部工具栏的「**上传**」按钮，并继续点击弹框的「**上传**」按钮，快应用开发工具会自动打带有 release 签名的 rpk 包，并上传至官网的开发者中心。

**注意：**

- 需要开发者在官网完善个人或企业信息之后，才能使用该功能。

- 若第一次上传，上传成功之后需要点击链接到官网填写相关信息。

- 上传时需检查是否更改了 manifest 里的 versionName 和 versionCode 字段，否则快应用开发工具将会有警告提示，上传的 rpk 的新版本不更改这两个字段有可能导致审核不通过。

- 如果快应用属于首次上传，快应用开发工具会上传并直接在 [快应用开发中心](https://www.quickapp.cn/myCenter/appManage/appList) 创建应用。

- 官网上传流程请参考 [快应用上传流程](https://www.quickapp.cn/docCenter/post/72) 。

## 上传至包管理平台

1. 可以通过点击顶部工具栏的【打包】按钮执行功能。

2. 检查证书

   检测在工程的 sign 目录中是否存在 certificate.pem 和 private.pem 文件。如不存在则提示用户去[生成证书](./certification.html)。

3. 打包成功

   打包成功之后，会在 dist 目录下生成带有 release 签名的 rpk 包。选择上传包管理平台（需要登录官网）。
