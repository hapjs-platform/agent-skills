# 远程预览

> 远程预览，是通过浏览器或者微信扫码预览编译后的结果，本节将介绍远程预览的使用。

## 打开项目

创建工程之后，快应用开发工具将自动打开新建的快应用工程，或者打开其他快应用项目。

## 打开远程预览功能

点击开发工具顶部工具栏的「**远程预览**」，即可打开远程预览功能，如下图：

## 使用远程预览功能

- 登录，登录平台帐号才能使用远程预览功能，如果没有账号可以先进行注册。
- 使用远程预览功能，需要先新建签名，可根据 IDE 的提示新建签名。
- 前置工作做完之后，点击远程预览，即可打包上传 rpk 至云端，并生成二维码，用户可以通过微信或者浏览器扫码的形式进行远程预览，无需在同一局域网下和使用调试器。
- 二维码的过期失效是 24 小时，过期后或者想查看最新代码的效果，请点击「**刷新**」按钮
