# 新建界面

> 了解快应用开发工具（简称 IDE）新建界面上各个模块的功能。

快应用开发工具（简称 IDE，[点此下载](https://www.quickapp.cn/docCenter/IDEPublicity)）是快应用团队打造的一站式快应用开发工具，提供了编码、调试、测试、上传等功能。

## 新建界面

### 简介

在快应用开发工具（简称 IDE）的新建界面，开发者可以根据项目类型进行 **新建项目**、**打开现有项目** 等相关操作。

**注：**

- 在该界面中，开发者可以通过下载模板插件之后，选择不同的行业模板进行二次开发。

- 在该界面中，可以跳转到官方文档。

- 在该界面中，选择「**小程序**」转换工具，在安装完插件之后，开发者可以通过该功能将微信小程序转化为快应用。
