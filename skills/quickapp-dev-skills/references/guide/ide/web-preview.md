# 模拟器预览

> 模拟器预览，是通过模拟器预览编译后的结果，本节将介绍模拟器预览的使用。

## 打开项目

创建工程之后，快应用开发工具将自动打开新建的快应用工程，或者打开其他快应用项目。

## 打开模拟器预览功能

点击开发工具顶部工具栏的「**模拟器**」，即可打开或者关闭模拟器预览功能，如下图：

## 使用模拟器预览功能

- 用户可以通过顶部工具栏上的按钮开启/关闭模拟器窗口和模拟器开发者工具窗口

- 调试器定制的 UX 面板，展示预览的 Dom 结构以及样式，可实时修改样式规则、命名以及元素属性。

- 调试器定制的 Data 面板，展示页面数据，主要指 .ux 文件中的 private、protected 字段，并支持自动刷新。

- 「**后退**」，「**刷新**」可以帮助开发者调试项目

- 展示二维码可以在手机上用调试器扫码直接安装项目，详情请见快速调试中 [扫码调试](./machine-debug.md)

- 查看日志功能，开发者可查看编译日志，发现问题。

- 模拟器分离功能，开发者可把模拟器从 IDE 上分离出来，单独展示。

- 左下角提供页面路径跳转以及页面路径和页面参数的查看和复制。

- 预览设置中，可关闭或开启**保存文件时自动刷新**、**重新启动编译**、**选择预览版本**、**切换设备**。

**注意：**
模拟器预览只是模拟真机上的效果，实际效果以真机上为准。
