# 新建项目

> 在开发工具中创建一个全新的快应用项目

## 打开创建快应用工程界面

- 通过 「**文件**」「**新建快应用工程**」菜单打开功能界面。
- 欢迎界面，点击「**新建工程**」 按钮打开功能界面。
- 侧边栏 `快捷入口` ，点击「**新建快应用工程**」 打开功能界面。

## 模版选择

切换到 **模版选择** 标签页，选择合适的模版，点击「**下一步**」即可。

**注意：**
IDE 中默认内置联盟标准模版工程，如需要更多模版工程可点击安装插件获取更多模版。

## 输入快应用工程信息

创建快应用工程需要输入以下信息：

- 选择路径：选择快应用工程存放的目录。
- 项目名称：快应用工程的文件夹名。
- 应用名称：与应用商店保存的名称一致，用于在桌面图标，弹窗等处显示。
- 应用包名：是区别于其他应用的唯一标识，推荐采用 **com.company.module** 的格式。

## 完成创建

最后点击「**完成**」按钮，快应用开发工具会按照开发者输入的信息创建新的快应用工程。新建成功后，快应用开发工具将自动打开新建的快应用工程。
