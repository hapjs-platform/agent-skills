# sitemap 检测工具

> 本节将介绍如何使用 sitemap 检测工具来进行搜索优化。

## 简介

sitemap 可增加快应用页面曝光，您可使用该功能来检测并提前发现 sitemap 配置的相关问题

## 入口

- 在上传之前，可在上传弹窗中选择 sitemap 检测功能。
- 预检测面板「**静态检测**」功能。
- 可点击「**查看**」「**命令面板**」打开命令输入框，输入命令 `Automatic Sitemap Pretest`，点击回车确认。

## 使用步骤

1. 准备环境： 若环境已准备好，则跳过此步骤。否则，开始下载 Chromium。

   **注：** 首次使用会安装工具相关依赖，在底部状态栏会有进度提示。

2. 检测 sitemap 配置： 若项目下已存在 sitemap 配置文件，则跳过此步骤。否则，点击 「**生成 sitemap 配置**」，自动创建 sitemap 配置文件。

3. 自动生成 sitemap 配置文件后，若是需要修改 sitemap 配置文件，可点击「**修改配置**」，进行修改。之后点击 「**继续**」进入下一步骤。

   **注：**若已经检测过，可以点击「**重新检测**」或者「**查看报告**」

4. 获取 RPK：IDE 会自动打包并获取 RPK 进行检测。

5. 生成检测报告：点击「**查看报告**」，可查看 sitemap 检测结果。根据 sitemap 检测结果修改完成后，点击「**重新检测**」，重新进行 sitemap 检测。
