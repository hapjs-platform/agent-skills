# 清理缓存

> 本节将介绍如何清除一些 IDE 的缓存

## 功能介绍

可以通过点击顶部工具栏的「**清缓存**」按钮执行功能。

1. 清除数据缓存：清除调试器面板的 localStorage 和 sessionStorage。

2) 清除调试器路径缓存：清除 USB 调试的调试器路径缓存，在 `.ide` 目录下的 `setting.json` 中的 `hapsetting.apkConfig` 字段。

3) 清除选择预览版本缓存：清除预览设置的选择预览版本缓存。

4) 清除选择设备缓存：清除预览设置的选设备缓存。

5) 清除消息通知缓存：清除后再重启 IDE 可看到最新的消息通知。

6) 清除全部缓存：清除以上全部缓存。
