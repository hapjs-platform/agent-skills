# 其他新建功能

> 在开发工具中新建卡片、新建组件、新建页面

通过本节你将学会：

- [新建卡片](#新建卡片)
- [新建组件](#新建组件)
- [新建页面](#新建页面)

## 新建卡片

### 打开功能

- 通过「**文件**」「**新建快应用卡片**」菜单打开 **创建新的卡片** 页面。

### 输入创建快应用卡片的信息

- 选择厂商：开发者根据自身的需求选择要创建的对应厂商的卡片。

- 卡片路径：

  - 左边：选择路径，默认目录为 /src/, 可以点击后修改，但必须在当前项目的 src 文件夹下。否则弹框提示“根目录必须在当前项目的 src 文件夹下”。

  - 右边：填写路径，格式为 name1/name2，不需要以/开头，路径中的文件夹名由字母、数字、\_组成，长度 1-255。当默认路径为 /src/ 时，右边不能为空。当选择路径不为 /src/ 时，右边可以为空。

- 卡片名称：根据卡片规范输入卡片名称。

- 组件名称：.ux 文件的文件名，例如输入 'hello' 对应生成 'hello.ux'。

- 卡片描述：对该卡片的描述信息，可为空。

- 最小平台版本号：设置运行该卡片的最小平台版本，必须为正整数，不提供则同 rpk 的最小平台版本号。

- 选择卡片模版。

### 完成创建

- 点击「**完成**」，开发工具会自动打开新创建的卡片文件。

- 开发工具会自动在 manifest.json 中的 router 下的 widgets 字段中配置卡片信息。

**注意：**

- 这里如果用户配置了 toolkit 并且修改了 sourceRoot 字段，页面的默认路径值将会相应的改变，页面路径选择输入框左边的按钮中的内容也会相应改变。

## 新建组件

### 打开功能

- 通过在文件树中「**右键**」文件夹打开 **创建新的组件** 页面。
- 通过「**文件**」「**新建快应用组件**」 菜单打开 **创建新的组件** 页面。

### 输入创建快应用组件的信息

- 组件路径：

  - 左边：选择路径，默认目录为 /src/， 可以点击后修改，但必须在当前项目的 src 文件夹下。否则弹框提示“根目录必须在当前项目的 src 文件夹下”。

  - 右边：填写路径，格式为 name1/name2，不需要以/开头，路径中的文件夹名由字母、数字、连字符、\_组成，长度 1-255。当默认路径为 /src/ 时，右边不能为空。当默认路径不为 /src/ 时，右边可以为空。

- 组件名称：可由字母、数字、下划线、连字符组成，不填写则取选中模版的名称。

- 选择组件模版。

### 完成创建

- 点击「**完成**」，开发工具会自动打开新创建的组件文件。

**注意：**

- 这里如果用户配置了 toolkit 并且修改了 sourceRoot 字段，页面的默认路径值将会相应的改变，页面路径选择输入框左边的按钮中的内容也会相应改变。

## 新建页面

### 打开功能

- 通过在文件树中「**右键**」文件夹打开 **创建新的页面** 功能界面。
- 通过「**文件**」「**新建快应用页面**」菜单打开 **创建新的页面** 功能界面。
- 通过 `命令面板` 输入 `Create A Hap Page` 打开 **创建新的页面** 功能界面。

### 输入创建的快应用页面信息

- 页面标题：在标题栏显示，相当于 titlebarText，不限格式

- 页面路径：

  - 左边：选择路径，默认目录为 /src/，可以点击后修改，但必须在当前项目的 src 文件夹下。否则弹框提示“根目录必须在当前项目的 src 文件夹下”。

  - 右边：填写路径，格式为 name1/name2，不需要以/开头，路径中的文件夹名由字母、数字、连字符、\_组成，长度 1-255。当默认路径为 /src/ 时，右边不能为空。当默认路径不为 /src/ 时，右边可以为空。

**注意：**

- 这部分格式规则较多，在填写时，红字提示格式错误。

### 完成创建

- 点击完成，开发工具会自动打开新建的页面。

- 新建的页面将会放到用户所选择的路径下。

- 同时插件会自动在 manifest.json 中的 router 下的 pages 字段和 display 下的 pages 字段中添加页面信息。

**注意：**

- 这里如果用户配置了 toolkit 并且修改了 sourceRoot 字段，页面的默认路径值将会相应的改变，页面路径选择输入框左边的按钮中的内容也会相应改变。
