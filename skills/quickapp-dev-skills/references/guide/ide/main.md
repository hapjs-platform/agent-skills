# 主界面

> 了解快应用开发工具（简称 IDE）主界面上各个模块的功能。

## 主界面

1. 功能面板：资源管理器、搜索、git 管理、debug 、插件市场、快捷入口、意见反馈等边栏

2. 菜单栏：文件、编辑、Hap、工具、选择、查看、转到、终端、窗口、帮助等基础功能

3. 工具栏：[关联快应用](./associate-quickapp.md)、[编译模式](./compile.md#编译模式)、显示/隐藏界面区域、[骨架屏](./skeleton.md)、[清缓存](./clear-cache.md)、[远程预览](./remote-preview.md)、[真机 USB 调试](./machine-debug.md)、[打包](./package.md)、[上传](./upload-quickapp.md)、[资源帮助](./resources.md)和登录功能

4. 输入与修改代码的区域，每款 IDE/编辑器 都必备的最基本功能

5. 调试窗口开发者工具

6. 模拟器预览窗口，请参考 [模拟器预览](./web-preview.md)
