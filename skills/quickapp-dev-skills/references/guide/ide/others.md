# 其他功能

> 了解开发工具提供的其他功能：如何获取快应用的资源或通知，如何反馈问题或联系我们

通过本节你将学会：

- [帮助菜单](#帮助菜单)
- [评分](#评分)
- [消息通知](#消息通知)

## 帮助菜单

「**帮助**」菜单包含「**欢迎使用**」、「**FAQ**」、「**联系我们**」、「**意见反馈**」子菜单，使用这些菜单，可以获取资源或反馈问题。

1. 欢迎使用

   通过「**帮助**」「**欢迎使用**」菜单，打开欢迎页。在欢迎页的下方，可以查看快应用生态的开放资源。

2. FAQ

   通过「**帮助**」「**FAQ**」菜单，打开 FAQ 链接。可以查看开发工具的常见问题。

3. 联系我们

   通过「**帮助**」「**联系我们**」菜单，打开联系页。可以扫码添加官方微信。

4. 意见反馈

   通过「**帮助**」「**意见反馈**」菜单，打开意见反馈页。填入问题信息，点击「**在 GitHub 中预览**」跳转至 GitHub 项目下，可向我们提交 issue。

   点击侧边栏的「**意见反馈**」图标，点击「**新建意见反馈**」，也可以打开意见反馈页。另外，该入口还支持搜索功能。

## 评分

- 点击状态栏的「**评分**」图标，打开评分弹窗。选择分数，输入意见，点击「**发送**」，即可完成评分。

  **注意**：如果是遇到 bug，则通过「**提交 bug**」或前面的意见反馈功能，提交问题。通过评分，容易因信息不足，无法复现和修复问题。

## 消息通知

- 点击状态栏的「**消息**」图标，打开消息通知。可以查看开发工具发送的官方资讯，比如新版本发布等。

- 有新消息时，开发工具会自动展示消息通知。如果你不希望如此，也可以关闭消息通知。打开「**首选项**」「**设置**」菜单，在搜索框输入 **Auto Show Messages** ，然后取消勾选即可。
