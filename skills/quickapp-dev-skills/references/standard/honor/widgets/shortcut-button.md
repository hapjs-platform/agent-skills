# 加桌按钮 shortcut-button

> 该组件与公共组件 [`shortcut-button`](../../public/widgets/shortcut-button.md) 接口一致（属性 / 样式 / 事件 / 默认值全等），本文档仅补充荣耀平台视觉与使用规范。

> **支持版本**
> - 卡片：不支持
> - 快应用 App：支持

## 使用规范

### 加桌组件视觉规范

1. 按钮文案需包含「加桌」或「桌面」，如「添加桌面图标」（默认居中显示）。
2. 按钮大小可自定义，有最大 / 最小尺寸限制，不支持百分比。
3. 按钮背景颜色可自定义，背景色和文本颜色不能相似。

### 加桌组件使用规范

1. 加桌引导不可遮挡页面内容。
2. 加桌按钮样式、颜色与快应用整体风格一致。
3. 不可干预用户正常使用快应用（如必须先加桌后才能继续浏览）。
4. 成功添加桌面图标后，加桌按钮需消失，避免重复点击。
5. 文案中包含「加桌领红包」「加桌领福利」等内容时，加桌后福利需有路径可查看，不可存在欺骗用户的加桌行为。
