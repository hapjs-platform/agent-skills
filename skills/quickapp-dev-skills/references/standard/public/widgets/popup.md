# popup `1000+`

## 概述

在点击控件或者某个区域后，浮出一个气泡来引导用户，气泡内容通过子组件来定义。如果设置了遮罩层，可通过点击遮罩层的任意位置退出，否则点击气泡外的任意区域退出

## 子组件

仅支持`<text>`

## 属性

支持[通用属性](common-attributes.md)

| 名称      | 类型                                                                                                           | 默认值 | 必填 | 描述           |
| --------- | -------------------------------------------------------------------------------------------------------------- | ------ | ---- | -------------- |
| target    | `<string>`                                                                                                     | -      | 是   | 目标元素选择器 |
| placement | left &#124; right &#124; top &#124; bottom &#124; topLeft &#124; topRight &#124; bottomLeft &#124; bottomRight | bottom | 否   | 弹出窗口位置   |

## 样式

支持[通用样式](common-styles.md)

| 名称       | 类型      | 默认值        | 必填 | 描述                                                                   |
| ---------- | --------- | ------------- | ---- | ---------------------------------------------------------------------- |
| mask-color | `<color>` | rgba(0,0,0,0) | 否   | 遮罩背景层的颜色，不设置时为全透明。假如只设置了颜色，透明度默认为 30% |

## 事件

支持[通用事件](common-events.md)

| 名称             | 参数                         | 描述                                        |
| ---------------- | ---------------------------- | ------------------------------------------- |
| visibilitychange | {visibility:visibilityValue} | 当显隐状态变化时回调，true 显示，false 隐藏 |
