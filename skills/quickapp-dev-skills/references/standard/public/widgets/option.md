# option `1000+`

## 概述

`<select>`的子组件，用来展示下拉选择具体项目

## 子组件

不支持

## 属性

支持[通用属性](common-attributes.md)

| 名称     | 类型        | 默认值 | 必填 | 描述                         |
| -------- | ----------- | ------ | ---- | ---------------------------- |
| selected | `<boolean>` | false  | 否   | 选择项是否为下拉列表的默认项 |
| value    | `<string>`  | -      | 是   | 选择项的值                   |

## 样式

支持[通用样式](common-styles.md)

## 事件

不支持
