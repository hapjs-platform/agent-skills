# section-header  `1090+`

## 概述

section-group 的子组件。section-header 是每一个分组的头部,支持 flex 布局，不支持 position。
section-header 需要依附在 section-group 上，不可单独存在。点击 section-header 可以显示或者隐藏对应 section-group 的子 section-item和子 section-group。
