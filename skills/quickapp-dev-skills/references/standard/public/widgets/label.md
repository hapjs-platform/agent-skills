# label

## 概述

为 input、textarea 组件定义标注

## 子组件

不支持

## 属性

支持[通用属性](common-attributes.md)

| 名称   | 类型       | 默认值 | 必填 | 描述               |
| ------ | ---------- | ------ | ---- | ------------------ |
| target | `<string>` | -      | 否   | 目标 input 组件 id |

## 样式

支持[通用样式](common-styles.md)

支持[text 样式](text.md)

## 事件

无
