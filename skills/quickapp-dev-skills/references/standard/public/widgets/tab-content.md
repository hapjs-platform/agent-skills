# tab-content

## 概述

[`<tabs>`](tabs.md)的子组件，用来展示 tab 的内容区，高度默认充满 tabs 剩余空间，子组件排列方式为横向排列

## 子组件

支持

## 属性

支持[通用属性](common-attributes.md)

| 名称       | 类型          | 默认值   | 必填   | 描述         |
| ------------- | ----------- | ----- | ---- | ---------- |
| scrollable `1040+` | `<boolean>` | true | 否 | 是否可以通过滑动切换页面。设置为false后，页面的切换需通过与 tab-bar 的联动实现 |
