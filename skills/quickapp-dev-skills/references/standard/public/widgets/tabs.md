# tabs

## 概述

tab 容器

## 子组件

仅支持最多一个[`<tab-bar>`](tab-bar.md)和最多一个[`<tab-content>`](tab-content.md)

## 属性

支持[通用属性](common-attributes.md)

| 名称  | 类型       | 默认值 | 必填 | 描述                 |
| ----- | ---------- | ------ | ---- | -------------------- |
| index | `<number>` | 0      | 否   | 当前 active tab 索引 |

## 样式

支持[通用样式](common-styles.md)

## 事件

支持[通用事件](common-events.md)

| 名称   | 参数                | 描述                          |
| ------ | ------------------- | ----------------------------- |
| change | {index: indexValue} | tabs 子组件 active 变化时触发 |
