# select `1000+`

## 概述

下拉选择按钮，点击会弹出一个包含所有可选值的下拉菜单，从该菜单中可以选择一个新值

## 子组件

仅支持`<option>`

## 属性

支持[通用属性](common-attributes.md)

## 样式

支持[通用样式](common-styles.md)

## 事件

支持[通用事件](common-events.md)，不支持 click 事件

| 名称   | 参数                | 描述                   |
| ------ | ------------------- | ---------------------- |
| change | {newValue:newValue} | 下拉选择器选择值后触发 |
